تسكاتي — نسخة PWA جاهزة لـ GitHub Pages

الملفات:
- index.html: صفحة الموقع الرئيسية
- manifest.json: بيانات التطبيق اللازمة للتثبيت
- service-worker.js: التخزين المؤقت ودعم فتح الصفحة الأساسية دون اتصال بعد زيارتها مرة
- icons/: أيقونات التطبيق

طريقة الرفع:
1. افتح مستودع GitHub الخاص بموقع تسكاتي.
2. ارفع محتويات هذا المجلد إلى جذر المستودع (Root)، وليس المجلد نفسه.
3. تأكد أن اسم الصفحة الرئيسية هو index.html.
4. من Settings > Pages تأكد أن GitHub Pages منشور من الفرع والمجلد الصحيحين.
5. افتح رابط الموقع المنشور عبر HTTPS، ثم استخدم قائمة Chrome وابحث عن Install app / تثبيت التطبيق.

ملاحظات:
- لا يمكن إجبار Chrome على إظهار رمز التثبيت بجوار العنوان؛ المتصفح يقرر وقت ظهوره وفق شروط التثبيت وسلوك المستخدم.
- في iPhone/iPad غالبًا يكون التثبيت من Share > Add to Home Screen في Safari.
- المهام محفوظة في localStorage على الجهاز والمتصفح نفسه، ولا تتم مزامنتها تلقائيًا بين الأجهزة.
- العمل دون اتصال يخص ملفات واجهة الموقع المخزنة مؤقتًا؛ تحميل الخطوط الخارجية قد يحتاج الإنترنت.
